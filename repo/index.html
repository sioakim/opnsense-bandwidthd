os-bandwidthd — package repository for OPNsense

Per-device bandwidth accounting for OPNsense: an interactive traffic dashboard, traffic alerting and a device classifier, built around the bandwidthd capture daemon. Source and documentation: github.com/sioakim/opnsense-bandwidthd.

Add the repository

As root on the firewall:

fetch -o - https://sioakim.github.io/opnsense-bandwidthd/install-repo.sh | sh

Then install os-bandwidthd from System → Firmware → Plugins, or with pkg install os-bandwidthd. The plugin pulls in the bandwidthd daemon and libgd automatically.

Or by hand

mkdir -p /usr/local/etc/pkg/fingerprints/bandwidthd/trusted
fetch -o /usr/local/etc/pkg/fingerprints/bandwidthd/trusted/bandwidthd \
  https://sioakim.github.io/opnsense-bandwidthd/fingerprints/trusted/bandwidthd
fetch -o /usr/local/etc/pkg/repos/bandwidthd.conf \
  https://sioakim.github.io/opnsense-bandwidthd/bandwidthd.conf
pkg update -r bandwidthd
pkg install os-bandwidthd

What you get

Packages are signed; pkg verifies every download against the fingerprint above. The repository is per-ABI (${ABI} in the URL, e.g. FreeBSD:15:amd64) and currently ships amd64 builds for OPNsense 26.7.

Remove

pkg delete os-bandwidthd bandwidthd
rm -f /usr/local/etc/pkg/repos/bandwidthd.conf
rm -rf /usr/local/etc/pkg/fingerprints/bandwidthd
